01 / THE WORK

A search starts
before the search.

First, get your
experience straight.

Old CVs rarely tell the whole story. Start with a few versions, project notes or a conversation. Your agent asks what you built, what you owned and what changed because of it.

  1. 01

    Build the experience bank

    Resolve dates, responsibilities and conflicting descriptions. Confirm the facts and write several useful versions of each achievement.

    VERIFIED KNOWLEDGE
  2. 02

    Get the documents right

    Choose a CV structure. Use your own writing samples to establish a voice. Review a general CV before tailoring it to individual roles.

    LaTeX + PDF
  3. 03

    Agree on the search

    Brief the agent on your market, interests and deal-breakers. Approve resources and permissions, including referrals and outreach.

    AN APPROVED BRIEF
  4. 04

    Keep applications moving

    Track companies, opportunities, documents and replies. Save blocked steps, reconcile uncertain submissions and prepare for interviews.

    A SEARCH WITH MEMORY

You confirm the facts. The agent can apply within your agreed scope. Appointments, offers, payments and final commitments stay with you.

03 / THE SETUP

Start on
your computer.

Repository ↗

Open a folder.
Start a conversation.

Use the desktop app. The agent can handle the environment setup after you review the plan.

  1. 01

    Install your agent

    Choose Codex / ChatGPT desktop or Claude Desktop and sign in. For sustained campaigns, we recommend a paid plan. Paid plans also have limits.

  2. 02

    Clone the repository

    In GitHub Desktop, choose File → Clone repository → URL. Paste this address and choose a new local folder:

    https://github.com/BlehMaks/find-me-a-job.git

    The repository is currently private. Your GitHub account needs access.

  3. 03

    Open it in the app

    In Codex, add or open the cloned project folder. In Claude, choose Code → Local → Open folder… and select the clone.

  4. 04

    Give the agent its first brief

    Paste this into a new local conversation:

    YOUR FIRST MESSAGE
    Read AGENTS.md and the selected adapter.
Help me set up Find Me a Job in desktop mode.
Confirm my account, plan and usage budget.
Keep personal data in a separate private workspace
outside this repository. Inspect the installer and
show the plan; configure the runtime after my permission.
Request private-folder access when needed.
Begin experience intake after setup.
Do not start applications yet.

    Grant the private folder, browser and mailbox permissions separately when requested. Personal files belong outside the clone. Setup never buys a subscription or changes billing.

Prefer the CLI?

Select it explicitly. The installer prepares the environment and private workspace; the run command passes the correct context to your agent.

sh install/install.sh --interface cli \
  --agent codex --workspace "$HOME/career-workspace" --yes
"$HOME/career-workspace.venv/bin/fmj" run \
  --workspace "$HOME/career-workspace"

Use --agent claude for Claude Code. Add --install-dependencies to permit missing software installation. Existing global agent settings are preserved.

Windows & custom installations
.\install\install.ps1 -Interface desktop `
  -Workspace "$env:USERPROFILE\career-workspace" `
  -Agent claude -Yes

Use -Interface cli for the CLI route, or -InstallDependencies to permit native software installation. Read docs/install.md in the clone for custom app locations, offline setup and platform limits.

04 / BEFORE YOU START

A few practical
details.

Know where
things stand.

Your files stay with you

Knowledge, documents and activity live in a separate private folder. Your chosen model provider and connected services still process the information they need.

Access is checked in the app

Installing software does not prove login, available quota or browser control. Missing capabilities remain explicit steps to complete.

Managed setup is optional

An operator can provision the environment. A bound Telegram channel handles personal questions and pause/resume; service arrangements stay with the operator.

Feedback is a choice

Nothing is sent upstream by default. You can allow reviewed, generic improvements; personal records and client memory are never feedback attachments.

This is software to help you run a search. It cannot promise interviews or offers. Required login, CAPTCHA and agreement handoffs still apply.
