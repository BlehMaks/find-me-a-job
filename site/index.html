05 / QUESTIONS

Before you
start a search.

Questions before
you start.

Can I use it as an AI resume builder?

Yes. Your agent builds a CV or resume from your confirmed experience, then tailors it to each job description. You get editable LaTeX source and a PDF. The workflow checks text extraction and the page layout before the CV is ready.

Does it include a cover letter generator?

Your agent writes a tailored cover letter when the application requires one, or when you ask for one. It uses your experience and the vacancy to explain why your work fits the role.

Can AI apply for jobs automatically?

Once you approve the search scope and permissions, the agent can prepare and submit job applications through the tools available to it. Signing in and some site-specific steps may need your input. You attend interviews and make the final decisions on offers.

Which job sites does it work with?

The search can use employer career pages, job boards, LinkedIn and email alerts. Applications go through official employer routes where available. Access depends on your agent's browser and mailbox tools and the requirements of each site.

What do I need to get started?

Use Codex or Claude Code with access to a separate private workspace. The technical setup covers installation and tool checks. For managed use, you'll need a paid agent subscription, a mailbox and a LinkedIn account linked to that mailbox.

06 / THE TECHNICAL SETUP

Start on
your computer.

Repository ↗

The technical bit.
Run it yourself.

Choose your agent. Review the setup. Keep your experience and documents in a separate private folder.

  1. 01

    Choose your setup

    Start from the source in Codex or Claude Code, or use a setup app: macOS · Apple Silicon / Windows · x64. On Mac, open the DMG, drag Find Me a Job Setup into Applications and open it there. On Windows, launch the EXE.

    The optional setup apps are unsigned pilot builds; macOS builds are not notarized. Your OS may warn or block them. See release notes and checksums, or use the source instructions.

  2. 02

    Review what gets installed

    Choose Codex / ChatGPT desktop or Claude Desktop. The wizard checks existing software, clones the source and prepares the private environment. Missing software installation needs your permission; some native steps need your confirmation.

  3. 03

    Open your project

    After PDF checks pass, use Copy first message. In Codex open the source folder shown by the wizard. In Claude, choose Code → Local → Open folder… and select it. Paste the message and grant access to the separate private folder.

  4. 04

    Confirm access. Begin with your experience.

    Sign in to your agent and confirm its plan and budget. We recommend paid access for sustained campaigns; paid plans also have limits. Browser and mailbox permissions are checked separately. The first conversation builds your experience base, before applications begin.

    Setup never buys a subscription or changes billing. Feedback is an explicit choice; signing in to GitHub does not send anything.

Prefer to clone manually?

Use GitHub Desktop: File → Clone repository → URL, then paste:

https://github.com/BlehMaks/find-me-a-job.git

Open that folder in your desktop agent. Ask it to read AGENTS.md, inspect the installer and prepare a separate private workspace after reviewing the plan. GitHub Desktop is optional; GitHub CLI is a separate tool.

Prefer the CLI?

Select it explicitly. The installer prepares the environment and private workspace; the run command passes the correct context to your agent.

sh install/install.sh --interface cli \
  --agent codex --workspace "$HOME/career-workspace" --yes
"$HOME/career-workspace.venv/bin/fmj" run \
  --workspace "$HOME/career-workspace"

Use --agent claude for Claude Code. Add --install-dependencies to permit missing software installation. Existing global agent settings are preserved.

Windows & custom installations
.\install\install.ps1 -Interface desktop `
  -Workspace "$env:USERPROFILE\career-workspace" `
  -Agent claude -Yes

Use -Interface cli for the CLI route, or -InstallDependencies to permit native software installation. Read docs/install.md in the clone for custom app locations, offline setup and platform limits.

Know where

Your files stay with you

Knowledge, documents and activity live in a separate private folder. Your chosen model provider and connected services still process the information they need.

Managed setup is optional

Want help running the campaign? Read about managed use. A bound Telegram channel handles personal questions and pause/resume.

Feedback is a choice

Nothing is sent upstream by default. You can allow reviewed, generic improvements; personal records and client memory are never feedback attachments.

This is software to help you run a search. It cannot promise interviews or offers. Required login, CAPTCHA and agreement handoffs still apply.
