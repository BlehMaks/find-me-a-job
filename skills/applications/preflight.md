# Actual form and attachment preflight

Perform after upload parsing/autofill and immediately before dispatch. A local filename list is not evidence of the form's actual attachments.

- Confirm bound candidate/account, canonical employer/requisition or call, route and expected recipient. Recheck exclusions, duplicate/uncertain operations, policy version, pauses and human-reserved decisions.
- Read final name/contact/location and every required field. Check exact question meaning, unit/scale, dynamic dates and qualifiers. Trigger normal form validation; fix missing or uncommitted values using supported controls. Recheck values reset by CV parsing.
- Inspect actual attached filenames, sizes, types, counts and any preview/confirmation. Verify local file ownership/content/hash and matching candidate/target/version against the bundle. An old ATS profile may retain another vacancy's CV; replace it rather than assuming the newest upload won.
- CV goes to CV/resume; letter to cover-letter; references, diplomas, portfolios and certificates to their corresponding fields. Never put a private brief, working notes, photos or an unrelated input file into an upload. Inspect authorized original supporting files without rewriting their contents.
- Honour each field's accepted type, size and count. If a general supporting packet already contains references, do not add the same references again. If only one reference is allowed, select the most relevant authorized one after reading it. Do not call a mixed packet a diploma-only document.
- Optional supporting upload failure is logged and does not automatically block an otherwise ready submission. Mandatory missing attachment becomes an exact blocker. No upload workaround may bypass a concrete tool-required handoff.
- Required agreements/declarations use confirmed facts and scoped authority. New material commitments and mandatory action-time confirmations need the responsible human. Paid actions remain human-reserved.
- Record exact final field values, attachment paths/filenames/hashes, candidate/opportunity/policy/bundle IDs, observed validation, time and relevant permissions privately. If anything changes before sending, repeat affected checks.

Stop dispatch for wrong client/file, unresolved mandatory fact, failed document gate, unmatched identity, required missing attachment, active pause, uncertain prior delivery or required handoff. Continue independent authorized work and ask only for the concrete remaining item.
