# One-off and scheduled campaigns

At activation choose a one-off run or explicit schedule with timezone, volume/resource budget, notification channel and summary cadence. No silent daily sweep is created from a one-time campaign. Use the host's supported scheduler only after scope is approved; persist campaign identity so multiple triggers cannot become concurrent outbound writers.

At each run reconcile in-flight/delivery-unknown operations, read effective policy/pauses/questions, then resume pending queue and planned source coverage. Reuse already completed catalogues; recheck live opportunity status when actionable. Group shared blockers and avoid repeated attempts until expiry or invalidating evidence. Keep independent work progressing.

Notify promptly for invitations, meaningful employer replies, new actionable handoffs, failures that require a person and important completion. Unchanged blockers or a quiet mailbox produce no repeated alert. Summaries show period, actual new unique submissions, separately recovered receipts, replies/invitations/outcomes and concrete remaining actions. Do not infer conversion rates from partial mailbox samples or count prepared documents as applications.

Save a compact checkpoint at pauses, capability changes and run end. Keep configured task tabs small; close only task-created inactive tabs after saving state. Sleep/screen lock/browser failure are distinct; do not change device settings from speculation. Honor pause before every new outbound action, including one started by a schedule.
