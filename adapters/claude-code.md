# Claude Code adapter

Follow `AGENTS.md` and `adapters/browser.md`. Use the official installed agent and explicitly configured integrations. Do not copy global settings over existing user configuration. Record OS, agent/integration versions, account prerequisites and actual capability evidence; native Windows and WSL are different environments.

Discover available tools, read their current instructions, then test browser navigation, synthetic form values and upload independently. Verify mailbox reading/sending and PDF visual review separately. CLI installed, browser connected and authenticated employer session are three different states. Missing integration leaves document-only work available, never a false ready-to-submit report.

Chrome integration may require direct account login, extension enablement and site permissions. Current provider instructions may reserve login/CAPTCHA or application access for a human. Persist a concrete handoff and resume after completion; do not bypass by shell, a new browser, protocol calls or a helper that uses stored passwords. Never send secret values to the reasoning context or journals.

References (verify at setup): [installation](https://code.claude.com/docs/en/setup), [Chrome](https://code.claude.com/docs/en/chrome), [computer use](https://code.claude.com/docs/en/computer-use). Computer-use availability is platform/account dependent. Provider updates can change these capabilities; use observed results and dated official documentation.
